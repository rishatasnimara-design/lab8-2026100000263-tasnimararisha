1.**What is version control?**
That controls and records changes to files over time.
**What is GIT?**
Free,open-source Distributed version control tool.
**What is GitHub?**
cloud-based platform used to host AND share git repositories.
**What is GIT bash?**
command-line software for windows used to run git commands.
**What are the main parts of GitHub?**
repositories,branches,commits,and pull requests.
**What are the stages of Git/GitHub?**
Working directory,staging area,Local Repository,and Remote repository.
